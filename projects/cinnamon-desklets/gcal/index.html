// App Overview

Key Functionality

Chronological View

Combines events from multiple Google Calendars and active items from Google Tasks into a single chronological desktop list.

Local Data Security

All API interactions run client-side on your own device. OAuth tokens are cached locally at ~/.config/gcal-desklets and are never transmitted to external servers.

Silent Token Refresh

Built-in Python helper handles headless OAuth authorization and automatically refreshes access tokens silently in the background.

// Compliance & Security

Google Data Access & Scope Transparency

Cinnamon Desklets explicitly requests access to two Google API scopes to render your schedule on your Linux desktop. Below is full transparency into why each scope is required and how the data is handled.

Requested Google OAuth Scopes

https://www.googleapis.com/auth/calendar.readonly

Google Calendar Read-Only Access

Purpose: Used exclusively to retrieve your upcoming events (titles, start/end times, locations, and calendar colors) so they can be rendered visually inside the desklet on your Cinnamon desktop canvas. No calendar entries are modified or created.

https://www.googleapis.com/auth/tasks

Google Tasks API Access

Purpose: Used to fetch your active Google Tasks and due dates so they can be displayed inline with your calendar agenda.

Data Handling & Privacy Guarantees

  • 100% Client-Side Operation: The application does not maintain any backend server or third-party database.
  • Zero Third-Party Sharing: Your calendar events, task items, and auth credentials are never sold, logged, or shared with third parties.
  • Local Credential Storage: Authorized tokens reside strictly inside ~/.config/gcal-desklets/token.json on your Linux machine.
  • Revocation: Access can be revoked at any time via your Google Account Security Permissions.

Installation & Configuration

Install required Python dependencies for Google OAuth pip3 install google-auth google-auth-oauthlib google-api-python-client # 3. Add "Google Calendar + Tasks" from Cinnamon Desklets settings
